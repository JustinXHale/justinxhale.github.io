# Resume PDF (optional)

This folder is for a **canonical PDF** you attach to applications (e.g. `justin-x-hale-resume.pdf`).

**Recommended workflow**

1. Keep **`/resume/`** (from `resume.md`) as the primary source of truth.
2. When you need a PDF: open that page locally or on GitHub Pages → **Print → Save as PDF**.
3. Save a copy here if you want a fixed file to upload to job portals; update it whenever you change `resume.md`.

If you add a PDF, link it from `resume.md` with something like:

`[Download PDF (PDF)]({{ site.baseurl }}/assets/resume/justin-x-hale-resume.pdf)`
